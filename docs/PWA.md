# اپ نصب‌شدنی (PWA) — iOS و اندروید

تسک **E9-15**. هدف: کاربر بتواند «بنزین» را از Safari (iOS) یا Chrome (اندروید) روی صفحه‌ی اصلی
نصب کند، بدون نوار آدرس باز شود، و بدون اینترنت هم حداقل پوسته‌ی برنامه را ببیند — نه صفحه‌ی خطای مرورگر.

## چه چیزی در مخزن است

| فایل                                   | نقش                                                                                       |
| -------------------------------------- | ----------------------------------------------------------------------------------------- |
| `apps/web/public/manifest.webmanifest` | نام/آیکون/رنگ/`standalone`/RTL؛ رنگ‌ها از همان توکن‌های `tokens.css` می‌آیند              |
| `apps/web/public/sw.js`                | سرویس‌ورکر: پوسته‌ی آفلاین، کش دارایی‌های استاتیک، عبور بدون کش از `/v1`                  |
| `apps/web/public/offline.html`         | کارت آفلاین خودبسنده (بدون باندل) که وقتی شبکه نیست نمایش داده می‌شود                     |
| `apps/web/public/icons/*`              | ۱۹۲، ۵۱۲، maskable‑۵۱۲، `apple-touch-icon` ۱۸۰، favicon ۳۲ و SVG                          |
| `apps/web/scripts/pwa-icons.mjs`       | تولید آیکون‌ها بدون هیچ وابستگی تصویری (ریاضی + PNG دستی) — قابل تکرار                    |
| `apps/web/src/lib/pwa.ts`              | منطق خالص: `isStandalone`، `shouldRegisterServiceWorker`، `readOnline`، `subscribeOnline` |
| `infra/web-nginx.conf`                 | هدرهای کش درست: `sw.js` با `no-cache`، `assets/` با `immutable`                           |

```bash
pnpm --filter @benzin/web icons   # بازتولید آیکون‌ها (تغییر رنگ برند = یک اجرا)
```

## سه قاعده‌ی کش

1. **`/v1/**` هرگز کش نمی‌شود.** نشست، کد یک‌بارمصرف، موجودی و سفارش‌ها به کاربر وابسته‌اند؛ یک پاسخ
   کهنه بدتر از یک پاسخ کند است.
2. **ناوبری = شبکه‌اول.** HTML تازه وقتی آنلاین هستیم؛ وقتی شبکه قطع است، پوسته‌ی کش‌شده و در نهایت
   `offline.html`.
3. **دارایی‌های استاتیک = stale‑while‑revalidate.** بارگذاری فوری، تازه‌سازی در پس‌زمینه.

نسخه در `const VERSION` است؛ هر تغییری در فهرست پیش‌کش باید نسخه را بالا ببرد تا `activate` کش‌های
قدیمی `benzin-web-*` را پاک کند. `sw.js` هرگز `immutable` سرو نمی‌شود، وگرنه کاربر تا یک سال روی
پوسته‌ی قدیمی قفل می‌شود.

## وقتی آفلاین هستیم چه اتفاقی می‌افتد

- بالای همه‌ی صفحه‌ها نوار «اینترنت قطع است؛ اطلاعات تازه نمی‌شود و تغییرات ارسال نمی‌شوند» ظاهر
  می‌شود (`AppShell` + `offline.banner` در `fa.json`).
- هیچ درخواستی صف نمی‌شود: v1 در v1 ساده است و ارسال پس‌زمینه (Background Sync) ندارد. کاربر باید
  بعد از وصل شدن، عمل را دوباره انجام دهد — این تصمیم آگاهانه است، نه فراموشی.
- نصب‌شدن اپ بدون اینترنت خودش یک قابلیت نیست؛ پوسته فقط مانع «دکمه‌ی خانه‌ی کاربر روی صفحه‌ی
  دایناسور» می‌شود.

## نصب روی iPhone — چک‌لیست دستی

سرویس‌ورکر فقط در بافت امن (`https:` یا `http://localhost`) و فقط در بیلد تولیدی ثبت می‌شود؛
`pnpm dev:web` عمداً ثبت نمی‌کند تا ماژول‌های نیمه‌ساخته کش نشوند.

```bash
pnpm -r build
pnpm --filter @benzin/api start          # :3000
pnpm --filter @benzin/web preview        # :5173 با پراکسی /v1
```

سپس روی دستگاه واقعی (داخل شبکه‌ی همان ماشین یا با یک تونل HTTPS):

1. در **Safari** باز کن → دکمه‌ی Share → **Add to Home Screen** → نام «بنزین» و آیکون قطره‌ی سبز.
2. آیکون را باز کن: باید بدون نوار آدرس و با نوار وضعیت روشن باز شود (`display: standalone`).
3. یک‌بار بازار و یک سفارش را باز کن (تا دارایی‌ها کش شوند)، بعد Airplane Mode را روشن کن و آیکون
   را از نو باز کن: پوسته + نوار آفلاین، بدون صفحه‌ی خطای Safari.
4. Airplane Mode را خاموش کن: نوار باید خودش برود (`online` event) و داده دوباره بار شود.
5. «Add to Home Screen» را حذف و دوباره نصب کن: نباید نسخه‌ی کش‌شده‌ی قدیمی بماند.

> این مرحله نیاز به دستگاه iOS واقعی دارد و در سندباکس انجام نمی‌شود؛ همان دلیلی که E9-15 تا این
> لحظه در وضعیت Blocked بود. کد و تست‌های خودکار حالا کامل‌اند؛ بند ۱ تا ۵ بالا تنها بخش «تأیید
> چشمی» باقی‌مانده است.

## محدودیت‌های شناخته‌شده

- **پوش iOS** از ۱۶٫۴ فقط برای اپ نصب‌شده ممکن است (Web Push با VAPID). مسیر وب‌پوش در E9-14/بک‌لاگ
  است؛ تا آن موقع پیامک کانال تضمینی است (A18 / A35).
- **اندروید بسته‌بندی‌شده** (Capacitor، تسک E9-16) به Android SDK/JDK نیاز دارد و در این محیط
  ممکن نیست؛ PWA فعلی همان تجربه را بدون Play Store می‌دهد.
- سرویس‌ورکر در `localhost` هم کار می‌کند، ولی در دامنه‌ی HTTP غیرلوکال ثبت نمی‌شود — همان قاعده‌ای
  که `shouldRegisterServiceWorker` رمزگذاری می‌کند.
