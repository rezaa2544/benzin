# پنل مدیریت (اپیک E8)

SPA مستقل در `apps/admin` (React 18 + Vite + Tailwind، فارسی و RTL) روی همان API.
ورود فقط با کد یک‌بارمصرف و همان حساب‌های کاربری انجام می‌شود؛ پنل هیچ رمز یا حساب محلی ندارد.

## اجرا

```bash
pnpm --filter @benzin/api dev        # API روی 3000
pnpm --filter @benzin/admin dev      # پنل روی 5174 (پراکسی /v1 → 127.0.0.1:3000)
```

ساخت حساب مالک (E8-10)، یک‌بار پس از `db:migrate`/`db:seed`:

```bash
pnpm --filter @benzin/api owner:create -- --phone 09123456789 --name "مالک بنزین"
```

دستور idempotent است: اگر شماره از قبل مالک باشد پیام می‌دهد، و اگر نقش دیگری داشته باشد
**ارتقا نمی‌دهد** (تغییر نقش فقط از پنل و با ثبت در لاگ ممیزی انجام می‌شود).
بدون `DATABASE_URL` دستور در حالت حافظه اجرا و صریحاً اعلام می‌کند که ماندگار نیست.

پنهان‌کردن منو فقط تجربه‌ی کاربری است؛ **همه‌ی مسیرهای نوشتن** با `requireRole('ADMIN','OWNER')`
در سرور محافظت می‌شوند و هر تلاش پشتیبانی/کاربر با `403` رد می‌شود (تست `admin.test.ts`).

## قواعد امنیتی

- `PUT /v1/admin/providers` هرگز کلید را برنمی‌گرداند: مقدار `apiKey` به `••••` تبدیل می‌شود و
  ارسال دوباره‌ی همان `••••` یعنی «کلید قبلی را نگه دار» (تست‌شده).
- حسابی که نقش `OWNER` دارد فقط توسط مالک قابل تغییر است.
- تعلیق دستی همان `suspendedUntil` موتور اعتماد را پر می‌کند، پس یک sweep زمان‌بند هر دو را آزاد می‌کند.
- هر تغییر کاربر/شهر/ارائه‌دهنده یک ردیف `audit_logs` می‌سازد و کاربر متأثر اعلان فارسی می‌گیرد.
- توکن دسترسی در `localStorage` نگه داشته می‌شود؛ با `401` نشست پاک و صفحه‌ی ورود نمایش داده می‌شود.

## معماری پنل

```
src/lib/api.ts          کلاینت JSON با خطاهای کددار (بدون وابستگی)
src/lib/session.ts      ذخیره‌ی نشست با fallback حافظه‌ای
src/lib/router.ts       مسیریابی هش (بدون سرور rewrite)
src/lib/permissions.ts  ماتریس نقش×صفحه — آینه‌ی گاردهای سرور
src/lib/settings-form.ts تبدیل ۲۹ کلید تنظیمات به فرم + اعتبارسنجی با همان bounds
src/components/         AppShell, DataTable, Modal, Badge, StatCard, Pagination, Notice
src/pages/              ۱۰ صفحه
```

هیچ درخواستی به `localhost` نمی‌رود: مسیرها نسبی‌اند و Vite (توسعه) یا Caddy (تولید)
`/v1` را به API می‌رسانند؛ بنابراین CORS و دامنه‌ی پیش‌نمایش بی‌اثر می‌شوند.
