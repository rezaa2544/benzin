# فهرست فازها و وظایف

**منبع حقیقت تابلوی Notion «بنزین» است** (صفحه‌ی پروژه → پایگاه‌داده‌ی Tasks)؛ این فایل فقط نقشه‌ی
کلی است و هیچ وضعیتی جدا از Notion نگه نمی‌دارد. ترتیب اجرا: فاز به فاز، داخل هر فاز بر اساس
وابستگی‌ها (`Depends On`)، هر بار یک تسک.

| فاز             | اپیک | موضوع                                                  | نمونه تسک‌ها                                      |
| --------------- | ---- | ------------------------------------------------------ | ------------------------------------------------- |
| M0 — پایه       | E0   | ساختار مخزن، ابزارها، CI، Spike ارائه‌دهندگان          | E0-01 اسکلت monorepo، E0-04 پیامک/درگاه/نقشه      |
| M0 — احراز هویت | E1   | OTP، نشست‌ها، دستگاه‌ها، امنیت ورود                    | E1-02 ورود OTP، E1-04 نشست و توکن                 |
| M0 — داده       | E2   | Drizzle، مهاجرت‌ها، ایندکس‌های حساس، seeds             | E2-01 اسکیمای Drizzle، E2-03 ایندکس‌های جزئی/GiST |
| M1 — معامله     | E3   | سفارش، جستجو، رزرو، ماشین حالت، چت                     | E3-02 جستجوی سفارش، E3-04 رزرو اتمیک              |
| M1 — زمان‌بندی  | E4   | BullMQ، انقضا، اعلان‌ها، websocket                     | E4-01 صف، E4-05 اعلان‌ها                          |
| M2 — پول        | E5   | پلن، اشتراک، پرداخت کارت‌به‌کارت، کیف پول              | E5-02 خرید اشتراک                                 |
| M2 — اعتماد     | E6   | اعتبار، گزارش تخلف، اختلاف                             | E6-02 گزارش تخلف                                  |
| M1/M2 — زیرساخت | E7   | Caddy، بکاپ، مانیتورینگ، امنیت عملیاتی                 | E7-05 🌐 بلاک‌شده (VPN لازم است)                  |
| M3 — پنل        | E8   | ۱۰ صفحه‌ی مدیریت                                       | E8-10 ساخت حساب Owner                             |
| M3 — کلاینت     | E9   | توکن‌ها و Style Guide، بازار، رزرو، چت، PWA، Capacitor | E9-02 Style Guide با تأیید اسکرین‌شات             |
| M3 — انتشار     | E10  | استقرار، بکاپ، مانیتورینگ، بار، امنیت، لانچ بانه       | E10-07 لانچ آزمایشی                               |

جزئیات معیارهای پذیرش هر تسک در Notion است. تصمیم‌های باز (D1…D10) در پایگاه‌داده‌ی Decisions
همان صفحه ثبت شده‌اند و تا زمانی که مالک پاسخ نداده باشد، مقدار پیش‌فرض ثبت‌شده در
[`ASSUMPTIONS.md`](ASSUMPTIONS.md) اعمال می‌شود.
