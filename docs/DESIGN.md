# سیستم طراحی اپ مشتری (اپیک E9)

منبع حقیقت برای رنگ، تایپوگرافی، فاصله و کامپوننت‌های `apps/web`.
توکن‌ها در `apps/web/src/styles/tokens.css` و نمونه‌ی زنده در مسیر `/` (صفحه‌ی راهنمای سبک).

> وضعیت تأیید: **در انتظار تأیید اسکرین‌شات** (E9-02). تا تأیید، صفحه‌های بعدی ساخته نمی‌شوند.

## اصول

- فارسی و RTL؛ فقط ویژگی‌های منطقی CSS (`margin-inline`, `inset-inline`, `border-s-*`).
  تست `tokens.test.ts` هر `margin|padding-left/right` در کامپوننت‌ها را رد می‌کند.
- هیچ کد رنگی در کامپوننت نیست؛ همه از توکن می‌آید (تست hex را رد می‌کند).
- فونت **Vazirmatn** خودمیزبان از بسته‌ی npm، فقط سه وزن ۴۰۰/۵۰۰/۷۰۰ (~۱۵۰ کیلوبایت).
- همه‌ی اعداد با ارقام فارسی و `tnum`؛ مبالغ با `formatToman`، حجم با «لیتر».
- کمترین اندازه‌ی لمسی ۴۴ پیکسل (`--tap-min`) و `:focus-visible` مشخص روی همه‌ی کنترل‌ها.
- `prefers-reduced-motion` انیمیشن‌ها را خنثی می‌کند.

## فاصله، شعاع، سایه

مقیاس چهارپیکسلی `--space-1…7` (۴ تا ۴۸ پیکسل). شعاع‌ها: `xs` ۸، `sm` ۱۲، `card` ۱۶،
`sheet` ۲۴، `pill` ۹۹۹. سایه‌ی کارت و شیت از دو توکن `--shadow-card` و `--shadow-sheet`.
ارتفاع نوار پایین `--nav-height` (۴rem) و حاشیه‌ی ایمن iOS با `--safe-bottom`.

## صفحه‌ها (E9-03…E9-14)

| مسیر                  | صفحه                | نکته‌ی طراحی                                                                           |
| --------------------- | ------------------- | -------------------------------------------------------------------------------------- |
| `/login`              | `LoginPage`         | دو مرحله (شماره → کد)، هم‌پوشانی `+98/0098`، شمارش معکوس ارسال دوباره از پاسخ سرور     |
| `/market?…`           | `MarketPage`        | فیلترها در URL (شهر/سوی معامله/سهمیه/مرتب‌سازی)، نوار آمار بازار، صفحه‌بندی مکان‌نما   |
| `/market/:id`         | `OrderDetailPage`   | نرخ رسمی و صرفه‌جویی خریدار کنار هم، دکمه‌ی رزرو فقط برای سفارش باز و غیرخودی          |
| `/new`                | `CreateOrderPage`   | همان قواعد سرور: بازه‌ی لیتر از تنظیمات، سقف نرخ = نرخ رسمی سهمیه                      |
| `/trade/:id`          | `TradePage`         | نقش (خریدار/صاحب سفارش) تعیین‌کننده‌ی دکمه‌ها؛ حلقه‌ی شمارش معکوس؛ شیت امتیاز ستاره‌ای |
| `/chat` و `/chat/:id` | `ChatPage`          | فهرست گفتگو + رشته‌ی پیام با پاسخ آماده، کارت تماس و شمار خوانده‌نشده                  |
| `/orders`             | `MyOrdersPage`      | دو زبانه‌ی «سفارش‌های من» و «رزروهای من»                                               |
| `/notifications`      | `NotificationsPage` | فیلتر خوانده‌نشده، خواندن همه، نشان روی هدر                                            |
| `/profile`            | `ProfilePage`       | کارت اعتبار (امتیاز/سطح/آمار)، اشتراک، دستگاه‌ها، خروج                                 |
| `/plans`              | `PlansPage`         | پلن‌ها + پرداخت کارت‌به‌کارت با مبلغ یکتا و دستور پرداخت فارسی                         |
| `/style-guide`        | `StyleGuidePage`    | مرجع توکن و کامپوننت‌ها (گیت تأیید طراحی)                                              |

قواعد مشترک: هیچ صفحه‌ای نشانی هاست نمی‌سازد (همیشه `/v1` نسبی)، هر خطا با `Notice` و
کد خطای سرور به فارسی نمایش داده می‌شود، و هر فهرست خالی `EmptyState` دارد.

## تست‌ها

۷۰ تست در ۱۱ فایل: توکن‌ها و کنتراست، تم، پنجره‌ی شمارش معکوس، مدل کارت سفارش و سطح
اعتبار، دیکشنری فارسی، مسیریابی و گارد نشست، نشست/نوسازی توکن، کلاینت API (۴۰۱، refresh
تک‌پروازی، خطای شبکه)، مدل بازار، فرم سفارش و ماتریس عمل‌های معامله.
اجرا: `pnpm --filter @benzin/web test`.

## گام بعدی

تأیید چشمی همین صفحه‌ها روی دستگاه واقعی؛ سپس `E9-15` (PWA/نصب) و `E9-16` (سوکت زنده‌ی
چت) که به ترتیب به هاست HTTPS و زیرساخت WebSocket نیاز دارند.
