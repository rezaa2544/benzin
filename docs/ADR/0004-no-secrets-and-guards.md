# ADR-0004 — هیچ رمزی در گیت، و اعتبارسنجی در مرز

**وضعیت:** پذیرفته‌شده

## تصمیم

1. پیکربندی فقط از محیط خوانده می‌شود (`config.ts` با اسکیمای Zod و بوت سریع‌شکست).
   `.env` در گیت نیست، `.env.example` هست.
2. اعتبارسنجی ورودی در مرز HTTP با اسکیماهای `@benzin/shared` انجام می‌شود؛ بدنه‌های ناشناس
   (`strict()`) رد می‌شوند، اعداد query با `coerce` تبدیل می‌شوند.
3. خطاها یک پاکت ثابت دارند `{ error: { code, message, details, requestId } }` و کلاینت فقط
   `code` را ترجمه می‌کند — پیام هرگز پارس نمی‌شود.
4. هر تغییر وضعیت سفارش/رزرو فقط از ماشین حالت `@benzin/shared` عبور می‌کند؛ وضعیت‌های مجاز
   و نقش مجاز در یک جدول گذارها تعریف شده‌اند، نه در ifهای پراکنده.
