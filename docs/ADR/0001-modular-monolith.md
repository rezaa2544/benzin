# ADR-0001 — مونولیت ماژولار روی Fastify

**وضعیت:** پذیرفته‌شده

## زمینه

محصول یک بازار دوطرفه‌ی جغرافیایی است: سفارش، رزرو، چت، اشتراک و پرداخت، پنل ادمین.
تیم کوچک است و زمان تا لانچ کوتاه. تعداد کاربران در فاز اول در حد چند هزار است.

## تصمیم

یک برنامه‌ی واحد (`apps/api`) با مرزهای ماژولار سخت: `domain` (موجودیت‌ها و قواعد)،
`ports` (قرارداد مخزن‌ها)، `modules` (سرویس‌های کاربردی)، `http` (لایه‌ی انتقال)،
`infra` (پیاده‌سازی مخزن‌ها). ماژول‌ها به‌صورت تابع خالص به هم تزریق می‌شوند، نه با import زنجیره‌ای.
میکروسرویس فقط اگر یک مرز واقعاً داغ شود (مثلاً اعلان‌ها) جدا می‌شود.

## پیامدها

- استقرار ساده (یک کانتینر API + Postgres + Redis).
- تست‌پذیری بالا: سرویس‌ها با مخزن درون‌حافظه‌ای و ساعت تزریقی تست می‌شوند.
- ریسک: وابستگی همه‌ی ماژول‌ها به یک فرایند. با صف BullMQ و جداسازی `Notifier` مهار می‌شود.
